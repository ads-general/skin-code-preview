# Skin Code — podgląd do review

Statyczny podgląd strony sprzedażowej kursu **Skin Code** (Olga Pavlenko /
@my.true.cosmetology), udostępniony do opinii przed publikacją.

- To **nie jest** wersja produkcyjna. Docelowy adres: www.mytruecosmetology.com
- Indeksowanie wyłączone (`robots.txt` + `noindex`), `canonical` wskazuje domenę docelową.
- Przyciski „Zapisz się" przewijają do cennika — płatności nie są jeszcze podpięte.
- Platforma kursowa i logowanie nie wchodzą w skład podglądu.
- Nagłówki bezpieczeństwa z `.htaccess` (CSP itd.) działają tylko na docelowym
  hostingu Apache, nie na GitHub Pages.

Generowane skryptem `tools/publish-preview.sh` z prywatnego repozytorium projektu.
